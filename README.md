حقيبة المعلم الشاملة — مشروع أندرويد أولي

هذا مشروع مصدر Android/Kotlin أولي وليس ملف APK جاهزًا للتثبيت. يتضمن واجهة عربية أولية وحفظًا محليًا وبعض النماذج؛ ما تزال وظائف التحصيل والنتائج والتصدير والنسخ الاحتياطي بحاجة إلى استكمال واختبار.

## بناء APK عبر GitHub Actions
1. ارفع جميع محتويات هذا المجلد إلى جذر مستودع GitHub (بما فيها `.github/workflows/build-android.yml`).
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Android APK** ثم **Run workflow**.
4. بعد نجاح التشغيل، افتح نتيجة التشغيل وابحث عن **Artifacts**.
5. نزّل `teacher-bag-debug-apk` وفك ضغطه للحصول على `app-debug.apk`.

ملف سير العمل يستخدم إجراءات مثبتة إلى SHA كاملة، ويشغّل Gradle 8.9 مباشرة؛ لذلك لا يحتاج إلى ملف `gradlew` أو مجلد `gradle/wrapper`.

ملاحظة: هذا المشروع ما يزال نموذجًا أوليًا، ونجاح البناء لا يعني أن جميع وظائف التطبيق مكتملة.
